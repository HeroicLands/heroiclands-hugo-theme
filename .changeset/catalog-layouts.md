The theme ships eleven catalog section layouts (`affliction`, `armorgear`,
`attribute`, `being`, `containergear`, `miscgear`, `mysticalability`,
`projectilegear`, `skill`, `trauma`, `weapongear`) and a `knowledgebase`
landing layout, each at both a top-level section path and a nested one, so a
consumer publishing one of these content types gets a purpose-built catalog
page — grouped by category, with type-specific columns — in place of the
generic list, regardless of how deep its own sections sit.
