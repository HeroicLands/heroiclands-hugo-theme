{{ end }} {{- /* A curated landing is the best navigation — a rules section groups its pages under editorial headings like "Key Concepts", which no hierarchy can infer. But gating the auto-list on "has no body" meant authoring an intro silently replaced the section's ONLY navigation, and hand-curated lists drift: one guide reached 41 pages linking 1, and another had quietly orphaned a page (issue #1115). So the auto-list is a GAP-FILLER: a section with a body lists only the pages that are not reachable from that body by following links. A landing whose hierarchy covers everything shows nothing extra, and a page can never become unreachable — a newly added page appears under "Orphaned Pages" until someone files it into the curated index. Taxonomy and term pages keep their own listing shapes below. */ -}} {{- $showAutoList := or (eq .Kind "taxonomy") (eq .Kind "term") (eq .Kind "section") -}} {{- /* WHAT THIS SECTION LISTS. Normally its own child pages: `.Pages` is what Hugo finds inside the section's directory, and for most of this theme's history that was also where a content page lived. `@heroiclands/package-build` stopped filing them there. Every content page is now emitted FLAT under the site's content mount — `/being-orc.md`, stating its own `url:` — because a section appears in no address, so the directory only ever existed to satisfy Hugo's idea of what a section is. No published address moved; only the paths did. A section directory then holds nothing but its own generated `_index.md`, `.Pages` is empty, and every declared section landing rendered "Nothing here yet." (issue #50). A theme cannot infer what is missing. The relationship between a section and its members survives only in the consuming package's build configuration, and it CANNOT be recovered from the section's name: a section name is a published URL its owner chose, and the two are deliberately free to differ — one knowledgebase publishes `/kb/user-guide/` for pages whose genre is spelled `userguide`, because a genre is an address segment and a segment carries no hyphen. Keying a filter on the directory name would re-introduce, here, exactly the coupling flat emission removed. So the SECTION SAYS WHAT IT LISTS, in two front-matter keys the build writes onto the generated landing from that configuration: listType A content type — `being`, `weapongear`, `doc`. Matched against the page's `Type`, which is the `type:` the build writes on every content page. listSubType Optional, and only ever alongside `listType`. Matched against the page's `subType`. Needed because one type can hold several genres: `rules`, `userguide` and `reference` are all `type: doc`, and a documentation tree mounted from a repository directory is `type: doc` carrying no `subType` at all — so `listType` alone would sweep all four together into whichever section asked first. Deliberately NOT Hugo's own `type:`. On an `_index.md` that key selects the template, so `type: doc` on a section landing would send it to `layouts/doc/list.html` instead of this file. The query is site-wide, which is the whole point: it asks what a page IS, not where its file sits, so it is indifferent to flat emission. It is the same query a consumer's own catalog layouts already run, which is why those layouts were never affected by the change. GATED ON AN EMPTY `.Pages`, so this is a fallback and not a replacement. A consumer still filing pages into section directories has a populated `.Pages` and never reaches it; a landing that declares no `listType` renders exactly as it did before, empty message included. Nothing here changes any site until its build starts emitting the keys. */ -}} {{- $members := .Pages -}} {{- if and (eq .Kind "section") (eq (len $members) 0) .Params.listType -}} {{- $members = where site.RegularPages "Type" .Params.listType -}} {{- with .Params.listSubType -}} {{- $members = where $members "Params.subtype" . -}} {{- end -}} {{- end -}} {{- /* Pages reachable from the authored body, matched on RelPermalink so the comparison survives aliases and wikilink resolution. The needle deliberately stops after the URL rather than closing the quote, so a link that carries a fragment counts. A rules landing reaches its Characters chapter as `…/characters-introduction/#body-structure`, and demanding the closing quote made that chapter read as unlinked. A trailing slash ends every RelPermalink, so the open-ended match cannot bleed into a sibling (`/rules/fate/` never prefixes `/rules/fate-points/`). Reachability is TRANSITIVE, because a curated corpus is a hierarchy rather than a flat index: a rules landing links ten chapter introductions, and each of those links its own pages — up to four hops deep (root → Trauma → Body → Injury → Bleeding). Testing only what the landing links DIRECTLY counted every page below the first hop as a leftover and dumped 59 of them under the reading path (issue #1322). So a page counts as listed when the body links it, or when any page already counted as listed links it. The walk runs to a fixed point: each pass appends the newly reached pages' content to the haystack, and the first pass that reaches nothing new stops it. Twelve passes is far past the depth of any corpus here (the rules need four), and the `$growing` guard makes the surplus passes free. */ -}} {{- $unlisted := $members -}} {{- if and (eq .Kind "section") .Content -}} {{- $haystack := .Content -}} {{- $reached := slice -}} {{- $growing := true -}} {{- range seq 12 -}} {{- if $growing -}} {{- $growing = false -}} {{- range $members -}} {{- if not (in $reached .RelPermalink) -}} {{- if in $haystack (printf "href=\"%s" .RelPermalink) -}} {{- $reached = $reached | append .RelPermalink -}} {{- $haystack = print $haystack .Content -}} {{- $growing = true -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- $unlisted = where $members "RelPermalink" "not in" $reached -}} {{- end -}} {{- /* Label the leftovers only when a curated body precedes them. With reachability transitive, anything still here is genuinely unreachable by reading — an orphan — so the heading says so rather than claiming to be the section's full contents. */ -}} {{- $labelList := and (eq .Kind "section") .Content -}} {{- if $showAutoList -}} {{- with $unlisted -}} {{- if eq $.Kind "taxonomy" -}}
