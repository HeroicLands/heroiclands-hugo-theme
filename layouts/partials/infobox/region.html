Climbs the parent chain to its continent(s) so a reader can walk up from any region to the continent above and the world above that. Fields rendered (all optional — guards keep missing data silent): - Name - Region(s) — the region(s) this one sits inside, when it is nested. - Continent(s) — a shortcode list, rendered as links when a matching page exists. A region may sit inside another region: Heliónis inside Hellád, Ta'Kheperu inside the Northern Fertile Region. That middle link used to be dropped — the card jumped straight to the continent — so a nested region's own `parent.regions` was recorded and never shown, and the chain a reader could walk had a hole in it. */ -}} {{- $ctx := . -}} {{- $name := "" -}}{{- with .Params.name.full }}{{ $name = . }}{{ end -}} {{- if not $name }}{{ $name = .Title }}{{ end -}} {{- $regs := slice -}} {{- $conts := slice -}} {{- with .Params.parent -}} {{- with .regions }}{{ $regs = . }}{{ end -}} {{- with .continents }}{{ $conts = . }}{{ end -}} {{- end -}}
