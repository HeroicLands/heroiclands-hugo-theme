{{- /* Region infobox — floated card at the top of a region page's content column. Text flows around it (see .geo-infobox in style.css). Climbs the parent chain to its continent(s) so a reader can walk up from any region to the continent above and the world above that. Fields rendered (all optional — guards keep missing data silent): - Name - Region(s) — the region(s) this one sits inside, when it is nested. - Continent(s) — a shortcode list, rendered as links when a matching page exists. A region may sit inside another region: Heliónis inside Hellád, Ta'Kheperu inside the Northern Fertile Region. That middle link used to be dropped — the card jumped straight to the continent — so a nested region's own `parent.regions` was recorded and never shown, and the chain a reader could walk had a hole in it. This is `type: place, subType: region` — a continent is the same subType carrying the tag `continent`, not a distinct one. The enclosing places are one flat `data.parents` list of shortcodes; each is resolved to a real page and sorted into "Region" or "Continent" by whether that page itself carries the `continent` tag. */ -}} {{- $ctx := . -}} {{- $data := dict -}}{{- with .Params.data }}{{ $data = . }}{{ end -}} {{- $name := "" -}}{{- with .Params.name.full }}{{ $name = . }}{{ end -}} {{- if not $name }}{{ $name = .Title }}{{ end -}} {{- $regs := slice -}} {{- $conts := slice -}} {{- range $data.parents -}} {{- $code := . -}} {{- $pg := first 1 (where (where $ctx.Site.RegularPages "Params.shortcode" $code) "Params.subType" "region") -}} {{- with index $pg 0 -}} {{- $isCont := false -}} {{- range .Params.tags }}{{- if eq . "continent" }}{{ $isCont = true }}{{ end }}{{- end -}} {{- if $isCont -}} {{- $conts = $conts | append $code -}} {{- else -}} {{- $regs = $regs | append $code -}} {{- end -}} {{- end -}} {{- end -}}
