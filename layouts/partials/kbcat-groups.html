{{- /* kbcat-groups — group a content type's pages by the nested frontmatter param `sohl.kbcat` and return an ORDERED slice of groups for rendering. Fully dynamic: it queries `site.RegularPages` at build time, so a consumer's own pages of the given type appear automatically on the next build — nothing here is hardcoded to any one consumer's catalog. Params (dict): type (string) Content type to scan (e.g. "weapongear"). This is the frontmatter `type`, not necessarily the Hugo section: a consumer may mount every content type under one shared section, in which case only `type` still tells them apart. titles (dict kbcat->str) Display titles for known kbcat values. order (slice of kbcat) kbcat values to emit first, in this order; a value with no pages is skipped. extras (bool) When true, any kbcat present in the data but absent from `order` is appended afterwards (alphabetically, title humanized) so newly introduced categories are never dropped — and a page carrying no `sohl.kbcat` at all is appended in one final group titled from `type`, rather than silently dropped. `GroupByParam` excludes a page whose param is absent or explicitly `null`, so without this a consumer whose notes carry no `kbcat` (an uncategorized item catalog) would lose every page of that type from the listing. Returns a slice of dicts: { cat, title, pages } where pages is sorted by title (ascending). Consumers render their own table/list markup. */ -}} {{- $type := .type -}} {{- $titles := .titles | default dict -}} {{- $order := .order | default slice -}} {{- $extras := .extras | default false -}} {{- $pages := where site.RegularPages "Type" $type -}} {{- $withCat := where $pages "Params.sohl.kbcat" "!=" nil -}} {{- $grouped := $withCat.GroupByParam "sohl.kbcat" -}} {{- $byCat := dict -}} {{- range $grouped -}} {{- $byCat = merge $byCat (dict .Key .Pages) -}} {{- end -}} {{- $out := slice -}} {{- $seen := slice -}} {{- range $cat := $order -}} {{- with index $byCat $cat -}} {{- $title := index $titles $cat | default (humanize $cat) -}} {{- $out = $out | append (dict "cat" $cat "title" $title "pages" (sort . "Title")) -}} {{- $seen = $seen | append $cat -}} {{- end -}} {{- end -}} {{- if $extras -}} {{- range $g := $grouped -}} {{- if not (in $seen $g.Key) -}} {{- $title := index $titles $g.Key | default (humanize $g.Key) -}} {{- $out = $out | append (dict "cat" $g.Key "title" $title "pages" (sort $g.Pages "Title")) -}} {{- end -}} {{- end -}} {{- $withoutCat := where $pages "Params.sohl.kbcat" "==" nil -}} {{- with $withoutCat -}} {{- $out = $out | append (dict "cat" $type "title" (humanize $type) "pages" (sort . "Title")) -}} {{- end -}} {{- end -}} {{- return $out -}}
