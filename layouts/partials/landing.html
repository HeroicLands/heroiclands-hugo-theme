Built separately they would not look like siblings, so the shape lives here and a package supplies only its own words and addresses. Rendered from the home page's front matter, by `layouts/index.html`, whenever that page declares `type: homepage` or carries a `landing` map. The whole contract is documented in README.md under "A package landing page"; the summary is: type "homepage" — what a package's `content/_index.md` declares to select this layout. (page front matter) landing.lead Opening paragraph. landing.install.heading Heading above the install block. landing.install.intro Prose above the URL. landing.install.url The manifest URL, set to be read and copied. landing.install.note Prose below it — the required host version, where to report a fault. landing.cards.heading Heading above the card grid. landing.cards.source "sections" builds one card per top-level site section from its title, description and permalink.
